The live domain is configured as:


## Google Indexing Steps

1. Publish the site publicly with HTTPS.
2. Open Google Search Console and add the domain or URL-prefix property.
3. Verify ownership.
4. Submit `https://www.mli-research.com/sitemap.xml`.
5. Use URL Inspection for the homepage and request indexing.
6. Make sure `robots.txt` is reachable at `https://www.mli-research.com/robots.txt`.
7. Search for the page after indexing with queries like:
   - `Casimir Michel`
   - `Casimir Michel Mettmann`
   - `Casimir Veranstaltungstechnik`
   - `Michel Veranstaltungstechnik`
   - `Michels Lighting Industries`
   - `MLI`
   - `AI stage lighting`
   - `AI lighting design`
   - `automated stage lighting`
   - `audio reactive lighting`
   - `audio-to-light research`

## Domain Move

- New canonical domain: `https://www.mli-research.com/`.
- Old domain: `https://michels-lighting-industries.com/`.
- If you still control the old domain in IONOS, configure an HTTP/301 redirect from the old root domain and old `www` subdomain directly to `https://www.mli-research.com/` and keep it active for at least 12 months.
- In Google Search Console, verify both the old and new domain properties, submit the new sitemap, then use Change of Address from the old domain to the new one once redirects are active.
- If the old domain must disappear instead of migrate, use Search Console Removals for the old domain prefix and keep the old site returning 404/410. Do not block the old domain with robots.txt if the goal is removal.

## What Helps Ranking Most

- A real custom domain is better than a random temporary URL.
- Link the site from LinkedIn, GitHub, Instagram, YouTube, or portfolio profiles.
- Get a few real external links from relevant pages, for example lighting, event technology, research, or local Mettmann profiles.
- Keep the name spelling consistent: `Casimir Michel`.
- Add more public project updates over time if the site grows beyond one page.
- Avoid keyword stuffing. Add search terms only where they naturally describe the project.
